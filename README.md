# Itzfizz Scroll-Driven Hero

A modern React website created for the Itzfizz Web Development Internship Assignment. The project uses GSAP for smooth scroll-based animations with a futuristic design.

## Features

- Scroll-driven GSAP animations
- Pinned hero section
- Responsive design
- Mobile navigation
- Glassmorphism UI
- Loading animations
- Reduced-motion support
- Optimized animations

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- GSAP + ScrollTrigger
- Lucide React
- JavaScript

## Run Locally

```bash
git clone [https://itzfizz-scroll-driven-frontend.vercel.app/]
cd frontend-assignment
npm install
npm run dev
